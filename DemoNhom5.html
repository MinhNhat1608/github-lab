Web demo NoSQL Injection

Demo này bám theo đúng bối cảnh: website đăng nhập dùng NodeJS + MongoDB, backend có phiên bản lỗi bảo mật và phiên bản đã fix để so sánh. Mục tiêu là giúp bạn quay video thuyết trình dễ hơn, nhìn trực quan hơn, và bám sát từng bước trong kịch bản.

1) Khu vực demo request

Thứ tự quay nên dùng:
B1 → B2 → B3 → B4 → B5 → B6, sau đó đổi sang Safe backend và gửi lại B2 hoặc B3 để so sánh.

2) Kết quả trả về

Chưa có request nào được gửi.
Đây là mô phỏng học thuật an toàn. Web này chỉ minh hoạ hậu quả của việc backend tin input người dùng quá sớm.

4) Ý chính để nói khi demo

  • NoSQL là nhóm cơ sở dữ liệu linh hoạt, MongoDB là dạng document database.
  • Lỗi xuất hiện khi backend dùng trực tiếp dữ liệu từ req.body để query.
  • Nếu không validate, input có thể không còn là string bình thường mà trở thành điều kiện truy vấn.
  • Hậu quả có thể là bypass login, truy cập nhầm tài khoản admin, hoặc trả ra quá nhiều dữ liệu.
  • Bản fix phải ép kiểu, validate input, sanitize, và không cho object đi thẳng vào query.
